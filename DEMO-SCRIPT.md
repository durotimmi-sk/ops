# TaskVault (OpsPilot) Demo Script

This script walks through the end-to-end capabilities of TaskVault for the **Vultr Agent Rush Challenge 1: Blast Radius Zero** submission.

---

## Part 1: Architecture & Containment Setup (30 Seconds)

1. Show the deployment running on Vultr VM:
   ```bash
   curl -i http://127.0.0.1:8000/api/health
   ```
2. Note key health check indicators:
   - `sourcing_worker_configured: true`
   - `sandbox_mode`: `docker` or `bubblewrap` (isolated execution)
   - `inference_policy`: `blast_radius_zero` with Vultr Serverless Inference provider enforced (`api.vultrinference.com`).

---

## Part 2: Evidence-Gated Sourcing Run (60 Seconds)

1. **Intake & Structured Clarification**:
   - Prompt: `Source nitrile examination gloves` (omit quantity).
   - Agent prompts with a structured clarification popup for quantity and unit (`500 boxes`).
   - Resume with quantity selected.

2. **Isolated Browser Worker Execution**:
   - Add target supplier URLs in the source attachment modal:
     - `https://example.com/product`
   - Run task:
     - The agent spins up the read-only Playwright worker inside the sandbox.
     - Navigates through the loopback allowlist proxy (`taskvault_egress.py`).
     - Live progress events stream via SSE: `browser.started` -> `browser.captured` -> `research.live` -> `task.completed`.

3. **Inspect Captured Evidence**:
   - Open the **Live browser evidence** drawer.
   - Click **Open screenshot** to view the full timestamped PNG evidence captured by the sandbox worker.
   - Observe extracted unit price, MOQ, and estimated landed cost. Missing fields remain `unknown` rather than hallucinated.

---

## Part 3: Containment Moment & Policy Enforcement (45 Seconds)

1. **Hostile Destination Demonstration**:
   - Trigger the containment verification endpoint or attempt an egress violation:
     ```bash
     curl -X POST http://127.0.0.1:8000/api/sandbox/test -H "Content-Type: application/json" -d '{"confirm": true}'
     ```
   - The test launches a worker that attempts to:
     - Read parent application secrets (`VULTR_INFERENCE_API_KEY`, database paths).
     - Access host filesystem and cloud metadata (`169.254.169.254:443`).
   - Result:
     - Egress proxy returns `403 Forbidden: Blocked by policy`.
     - Zero environment secrets are visible in worker memory.
     - Teardown status confirms temporary directories destroyed upon worker exit.

---

## Part 4: Human-in-the-Loop Action Approval (30 Seconds)

1. Select the top-ranked offer.
2. Click **Request quote** or **Create Purchase Order**:
   - A draft PO is generated with landed cost, buyer profile address, and delivery timeline.
   - Action status remains **Pending Approval**.
   - No external API, email, or webhook is triggered until the operator clicks **Approve**.
3. View the **Activity Ledger**:
   - Every action and event is hash-chained with SHA-256 integrity verification.

---

## Part 5: Vultr Serverless Inference Narrative (15 Seconds)

1. Show the generated executive summary generated by Vultr Serverless Inference:
   - Highlighting cost trade-offs, lead time, and citing exact screenshot evidence IDs.
   - End with confirmation of Blast Radius Zero compliance.
